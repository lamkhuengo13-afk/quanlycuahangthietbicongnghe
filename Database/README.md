
# Database - Quản lý cửa hàng thiết bị công nghệ

Thư mục lưu trữ các tập lệnh SQL và tài liệu thiết kế cơ sở dữ liệu của dự án.

## Danh sách tập lệnh

| Tên tập tin | Chức năng |
|---|---|
| 01_CreateDatabase.sql | Khởi tạo cơ sở dữ liệu |
| 02_CreateTables.sql | Tạo các bảng dữ liệu |
| 03_CreateConstraints.sql | Thiết lập các ràng buộc |
| 04_InsertSampleData.sql | Thêm dữ liệu mẫu |

## Hệ quản trị cơ sở dữ liệu

Microsoft SQL Server

## Công cụ

SQL Server Management Studio (SSMS)
