
# QUẢN LÝ CỬA HÀNG THIẾT BỊ CÔNG NGHỆ

## 1. Giới thiệu

Dự án xây dựng ứng dụng quản lý cửa hàng thiết bị công nghệ,
hỗ trợ quản lý sản phẩm, khách hàng, nhân viên, tài khoản,
nhập hàng và bán hàng.

## 2. Công nghệ sử dụng

- Ngôn ngữ lập trình: C#
- Nền tảng: .NET 10
- Giao diện: Windows Forms
- Hệ quản trị cơ sở dữ liệu: Microsoft SQL Server
- Công nghệ truy cập dữ liệu: ADO.NET
- Môi trường phát triển: Visual Studio 

## 3. Kiến trúc hệ thống

Ứng dụng được tổ chức theo kiến trúc 3-Tier:

- DTO: Data Transfer Object
- DAL: Data Access Layer
- BUS: Business Logic Layer
- GUI: Graphical User Interface

## 4. Cấu trúc repository

- Database: Các tập lệnh SQL và tài liệu cơ sở dữ liệu.
- Source: Mã nguồn ứng dụng.
- Documents: Sơ đồ thiết kế và hình ảnh minh chứng.
